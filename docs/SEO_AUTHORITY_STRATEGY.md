# SignalRate SEO authority strategy

## Scope

Milestone 15 builds useful, reviewable topic clusters around existing SignalRate tools. It does not create doorway pages, synthetic authors, purchased links, fabricated data, or claims of ranking outcomes. English remains the default language; only the six fully translated flagship tools are indexable in all ten supported languages.

## Published clusters

| Cluster | Primary guide | Main tools |
| --- | --- | --- |
| Internet performance | `/guides/internet-speed` | Speed test, latency test, bandwidth and download-time calculators |
| IP addressing | `/guides/ip-address` | What Is My IP, IP lookup, ASN and reverse DNS |
| JSON | `/guides/json` | JSON formatter, validator and conversion tools |
| Password security | `/guides/password-security` | Password generator and related local developer utilities |
| Time zones | `/guides/time-zones` | Time-zone and Unix timestamp converters |
| Currency exchange | `/guides/currency-exchange` | ECB-reference currency converter |
| SSL/TLS | `/guides/ssl-tls` | Certificate, chain, TLS-version and HTTPS checks |
| DNS | `/guides/dns` | DNS, reverse-DNS and email-security checks |

Tools link to the relevant guide near their explanatory content. Guides link back to concrete tools with a reason to use each one. The footer exposes the guides, data coverage, API and source-policy hubs so the clusters do not depend on sitemap discovery alone.

## Linkable evidence assets

`/data`, `/data/telecom`, `/data/calling-codes`, `/data/mcc-mnc`, `/data-sources`, `/methodology`, `/data-policy`, and `/api` explain the real data surface and its limits. Current factual counts are 248 UN M49 countries/areas, 241 verified calling-code relationships, 27 reviewed German MCC/MNC assignments, and three explicitly matched public operator identities. MCC/MNC is expressly partial and regulator-by-regulator.

## Multilingual publication rule

The six translated flagships are the speed test, public-IP checker, password generator, JSON formatter, currency converter and time-zone converter. Each locale has translated metadata, H1, introduction, controls, explanatory sections, FAQs, privacy/limitations text and breadcrumbs. These pages use a self-canonical and full `hreflang` set with English as `x-default`. Other locale-prefixed pages remain usable with the existing English-canonical `noindex, follow` fallback until their important content is fully reviewed.
